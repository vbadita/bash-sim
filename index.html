bash, in your browser

A Bash 5.2 interpreter and the usual GNU/Linux commands (ls, grep, sed, awk, find, tar, nano, vim, top and about 250 more), written in JavaScript. Everything runs on this page: there is no server and nothing you type leaves your browser. Files are kept in this browser's storage.

Simulated, not real: processes, users, sudo, the package manager and the network (ping, curl and wget answer only a few canned hosts).

Type help, man bash or cat README.md to start; reset-sim wipes the machine.
